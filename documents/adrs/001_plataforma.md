# Contexto

A aplicação precisa ser entregue em tempo hábil e ser capaz de se integrar facilmente aos computadores disponíveis na Clínica.

# Decisão

A solução será desenvolvida como uma aplicação Web, de forma a ser acessível pela maior parte dos computadores com acesso a internet.

# Consequências

## Positivas

- Uma única base de código para atender diversos sistemas operacionais.
- Ampla disponibilidade de bibliotecas e frameworks.

## Negativas

- O desempenho é inferior a de uma aplicação nativa.
- Mais dependente a uma boa conexão com a internet que um client local instalado em cada máquina.

## Alternativas Consideradas

- Aplicação desenvolvida em um framework C# apenas para Windows.
