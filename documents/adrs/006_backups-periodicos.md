# Contexto

Os dados dos sistema devem ser resilientes, perca de informações de tutores ou agendamentos pode ser catastrófico.

# Decisão

São gerados backups periódicos do banco de dados.

# Consequências

## Positivas

- Possibilidade rollback no caso de incidente no banco de dados.

## Negativas

- Custo extra de armazenamento.
